# Security policy

The supported version is the current `main` branch and the release at
[confluon.com](https://confluon.com/).

Report a suspected vulnerability privately through
[GitHub Security Advisories](https://github.com/tre-systems/confluon/security/advisories/new).
Include the affected browser or platform, reproduction steps, and likely impact.
Do not include credentials, private URLs, or personal data.

Use a public issue for ordinary bugs that do not expose users, deployment
credentials, or the software supply chain.
